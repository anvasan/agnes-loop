# 📝 Стратегия контента (SoftZor)

## Principles
Каждый кусок контента ДОЛЖЕН быть searchable, shareable, или обоим. Приоритет: сначала searchable.

## Searchable content
Целевые запросы через GSC:
- **Awareness:** «что такое», «как выбрать»
- **Consideration:** «лучшие», «топ», «vs», «альтернативы»
- **Decision:** «цена», «отзывы», «бесплатный тариф»
- **Implementation:** «шаблоны», «туториал», «настройка»

## Shareable content
- Data-driven analysis
- Expert roundups
- Behind-the-scenes прозрачность
- Controversial takes на основе данных

## Content Pillars для SoftZor
1. Обзоры ПО (carousels, топ-N)
2. Сравнения (X vs Y)
3. Инсайты рынка (тренды, новости)
4. Туториалы (настройка, интеграции)
5. Кейсы (как украинский бизнес использует)

## Keyword research по buyer stage
| Stage | Модификаторы | Пример |
|-------|-------------|--------|
| Awareness | что такое, как выбрать | CRM для малого бизнеса |
| Consideration | лучшие, топ, vs | CRM системы сравнение |
| Decision | цена, отзывы | Лучшая CRM Украина 2026 |
| Implementation | шаблоны, туториал | Настройка CRM Монобанк |

## Source ideas
- Reddit: site:reddit.com [niche]
- Quora: site:quora.com [topic]
- Product Hunt, Indie Hackers
- Поддержки тикеты (повторяющиеся вопросы → статьи)
- Продажи (возражения → контент чтобы устранить)
