# Навык: Написание статей блога

## Обзор

Создаёт SEO-оптимизированные статьи для блога softzor.com.ua. Статьи служат основному драйверу органического трафика из Google.

## Типы статей

| Тип | Цель | Объём | Частота |
|-----|------|-------|---------|
| TOP-N обзор | SEO-трафик по категории | 8000-12000 зн | 2-4/месяц |
| Сравнение A vs B |SEO-трафик по низкочастотникам | 5000-8000 зн | 1-2/месяц |
| Обзор одного продукта | SEO-трафик + партнёрки | 3000-5000 зн | По мере необходимости |

## Шаблон статьи ТОП-N

```markdown
# H1: ТОП-[N] [категория ПО] для [украинский бизнес / аудитория] в 2026

<!-- Smart Summary — быстрый выбор -->
[3-4 строки: кому какой продукт подходит. Краткая таблица.]

## H2: Почему [тема] важна для украинского бизнеса в 2026
→ контекст рынка, цифры, тренды

## H2: Критерии выбора
→ 4-6 конкретных критериев для украинского рынка

## H2: Обзор лучших [категория]
### H3: 1. [Название] — [слоган/ключевое преимущество]
→ суть + преимущества + для кого + цена + UA-интеграции

### H3: 2. [Название] — [слоган/ключевое преимущество]
...

## H2: Сравнительная таблица

## H2: Как выбрать (чеклист)

Ответ.

Ответ.

## H2: Вывод
[Краткое резюме + призыв к действию]
```

## SEO-правила (Rank Math)

### rank_math_title
- Максимум 55 символов (не 60 — запас для Google)
- Обязательно: название + ключевой запрос + выгода
- Синтаксис свободный (НЕ жёсткий шаблон)
- Запрещено: "Цены", "2024", "Отзывы" в заголовках

### rank_math_description
- Максимум 155 символов
- Обязательно: ключевой запрос + краткое описание
- Призыв к действию в конце

### focus_keyword
- Основной ключевой запрос, по которому статья ранжируется
- Должен встречаться в H1, первом абзаце, минимум 2 раза в тексте
- Не дублировать другие статьи на сайте

### rank_math_permalink
- Чистый slug на русском или транслите: `/blog/toп-crm-dlya-malogo-biznesa`

## Требования к контенту

1. **Все программные продукты — реально существующие** на softzor.com.ua. Ссылки на карточки через WP REST API перед написанием.
2. **Приоритет** — программы с партнёрскими ссылками.
3. **Украинский контекст** — интеграции с Новой Почтой, Монобанком, ПриватБанком, ПРРО, локализация.
4. **Не упоминать** запрещённые бренды (стоп-лист RU/BY).
5. **Реальные цены** — только с официальных сайтов /pricing страниц.
6. **Не выдумывать** сравнения продуктов — только проверяемые факты.

## Построение статьи

1. **Исследование:** Запросить текущие статьи блога через `GET /wp/v2/posts?lang=ru&per_page=20`
2. **Анализ пробелов:** Проверить categories Reference — какие категории имеют < 5 карточек
3. **Подбор ключевых слов:** На основе пробелов в категориях → определить запросы
4. **Написание:** Следовать шаблону ТОП-N
5. **Создание черновика:** `POST /wp/v2/posts` со статусом draft
6. **Заполнение мета:** Через аcf-поля или post_content HTML
