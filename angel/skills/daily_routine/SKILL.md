# 🌅 Ежедневная рутина (Daily Routine)

## Триггеры
| Команда | Режим | Описание |
|---------|-------|----------|
| `старт`, `доброе утро` | Утро | Утренняя сводка |
| `закрытие`, `итоги дня` | Вечер | Вечернее закрытие |
| Cron `0 9 * * *` | Утро | Авто в 9:00 |
| Cron `0 21 * * *` | Вечер | Авто в 21:00 |

## ☀️ Утренний круг (09:00)

### Шаг 1. Статус черновиков WP
```
GET https://softzor.com.ua/wp-json/wp/v2/software?status=draft&per_page=100
GET https://softzor.com.ua/wp-json/wp/v2/posts?status=draft&per_page=100
```
Для каждого черновика: название, тип (карточка/статья), дата, что осталось.

### Шаг 2. Загрузка контекста
- Прочитать последний журнал из Obsidian → раздел «📋 На завтра»
- Раздел «📝 В процессе» = незавершённые задачи

### Шаг 3. Метрики GSC/GA (если подключены)
- Посещения вчера / за неделю
- Топ-страницы
- Новые ключевые слова
- Изменения позиций

Если GSC/GA не подключены → отметить: «📊 Метрики: GSC/GA не подключены»

### Шаг 4. ПЛАН НА ДЕНЬ
На основе незавершённых задач, gap-analysis, контент-календаря.

Типовой план:
| Тип задачи | Кол-во | Описание |
|------------|--------|----------|
| Карточки ПО | 2–3 | Конкретные программы |
| Статья блога | 0–1 | Если категория 5+ карточек |
| Посты соцсети | 2–3 | Анонсы, инсайты |
| Доработки | по ситуации | Обновление карточек |

Приоритизация:
1. 🔴 Критические — незавершённые задачи
2. 🟡 Важные — новые карточки в пустых категориях
3. 🟢 Обычные — контент, оптимизация

### Шаг 5. Возможности рынка
- Проверить тренды (1–2 идеи для исследования)
- Сезонные возможности

### Формат утренней сводки
```
☀️ УТРЕННЯЯ СВОДКА — [дата, день недели]
═══════════════════════════════════════

📋 ЧЕРНОВИКИ
├── 🟡 [Название] — карточка ПО, создана [дата]
└── Всего: N черновиков

📊 МЕТРИКИ
├── Посещения вчера: N (↑/↓ N%)
└── Топ-страница: [название]

📌 ПЛАН НА СЕГОДНЯ
├── 1. 🔴 [Задача — приоритет]
├── 2. 🟡 [Задача]
└── 3. 🟢 [Задача]

⚡ ПРИОРИТЕТ ДНЯ
└── [Главная задача + почему]

═══════════════════════════════════════
Готова к работе! С чего начнём? 🚀
```

## 🌙 Вечернее закрытие (21:00)

### Шаг 1. Итоги дня
| Категория | Что фиксировать |
|-----------|-----------------|
| Карточки ПО | Созданные / обновлённые |
| Статьи блога | Созданные / обновлённые |
| Посты соцсетей | Подготовленные |
| Исследования | Проведённый анализ |
| Решения | Принятые решения |

### Шаг 2. Сохранение данных
1. Журнал работы → `G:\Мой диск\Obsidian_Brain\Журнал_Работы\YYYY-MM-DD.md`
   - **НИКОГДА не перезаписывать!** Только дополнять
2. Brain Base → обновить Context Master, Decisions Log, Трекер

### Шаг 3. Задачи на завтра
- Незавершённые текущие
- Следующие по приоритету
- Запланированный контент
