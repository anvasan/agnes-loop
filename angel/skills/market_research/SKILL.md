# 🔍 Исследование рынка ПО (SoftZor)

## Триггеры
- `[анализ рынка]` — полный анализ всех категорий
- `[gap-analysis]` — поиск пробелов в категории или всём каталоге
- `[исследование]` — исследование конкретного сегмента
- Вопрос: «Какие программы добавить?», «Что есть в категории X?»

## Алгоритм работы

### Шаг 1. Получить категории сайта
```
GET https://softzor.com.ua/wp-json/wp/v2/software_category?per_page=100
```
- Пагинация: `&page=2`, `&page=3`...
- Оставить только RU-категории: slug НЕ заканчивается на `-en`
- Построить дерево: родитель → дочерние

### Шаг 2. Получить программы
```
GET https://softzor.com.ua/wp-json/wp/v2/software?per_page=100&status=publish
```
- Маппинг программ к категориям
- Посчитать количество в каждой категории

### Шаг 3. Gap Analysis
| Кол-во программ | Статус | Приоритет |
|-----------------|--------|-----------|
| 0 | 🔴 Пустая категория | Критический |
| 1–2 | 🟡 Недостаточно | Высокий |
| 3–4 | 🟠 Ниже нормы | Средний |
| 5–10 | 🟢 Норма | Низкий |
| 10+ | ✅ Хорошее покрытие | Мониторинг |

Цель: 5–10 программ в каждой категории.

Для категорий с 0–2 программами: `search_web` по запросам:
«лучшие [категория] программы Украина 2025–2026», «[category] software Ukraine»
