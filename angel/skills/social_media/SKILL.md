# 📱 Генератор контента для соцсетей (SoftZor)

## Триггеры
- `[пост] Тема` — создать пост на тему
- `[контент-план]` — контент-план на неделю
- Автопредложение после создания карточки/статьи

## Типы постов

### 1. Анонс программы (Software Announcement)
**После создания карточки ПО.**
Объём: 300–500 символов.

```
🆕 [Название] — [описание 5-7 слов]

[2-3 предложения: что делает, для кого, фишка]
[1 предложение: почему актуально для Украины]

💰 Цена: [цена]
🌍 Страна: [страна]

👉 Обзор: [ссылка]

#[категория] #украина #[название]
```

### 2. Промо статьи блога
**После публикации статьи.**
Объём: 300–500 символов.

```
📊 [Заголовок статьи — сокращённый]

[Интригующий вопрос или проблема]

В статье:
✅ Пункт 1
✅ Пункт 2
✅ Пункт 3

📖 Читать: [ссылка]

#обзор #[категория] #топ #украина
```

### 3. Инсайт рынка
**При обнаружении тренда/новости.**
Объём: 300–500 символов.

```
💡 [Факт или тренд — 1 предложение]

[Контекст: почему это важно — 2-3 предложения]
[Значение для украинского бизнеса]

#тренды #софт #бизнес #украина
```

### 4. Сравнение X vs Y
**Когда есть 2 похожие программы в категории.**
Объём: 400–600 символов.

```
⚔️ [A] vs [B] — что выбрать?

[A]:
✅ Преимущество 1
❌ Недостаток

[B]:
✅ Преимущество 1
❌ Недостаток

🏆 Вердикт: [рекоммендация]
👉 Подробное: [ссылка]
```

## Платформы

### Telegram канал
- Markdown форматирование (жирный, курсив, ссылки)
- 2–3 эмодзи для структурирования
- Ссылки в конце поста
- OG-изображение подтянется автоматически

### Facebook страница
- Простой текст (без Markdown)
- 2–3 эмодзи умеренно
- Хэштеги: 3–5 штук в конце
- Вопрос аудитории для вовлечения

## Контент-план
Частота: 3–5 постов в неделю. Микс не более 2 одного типа подряд.

Лучшее время (Киев, UTC+2/+3):
| Время | Описание |
|-------|----------|
| 09:00–10:00 | Утренний пик |
| 12:00–13:00 | Обеденный перерыв |
| 18:00–19:00 | Вечерний пик |

Формат плана:
| День | Платформа | Тип | Тема | Время | Статус |
|------|-----------|-----|------|-------|--------|

## Правила
- Тон: дружелюбный эксперт
- Эмодзи: 2–3 на пост
- **ЗАПРЕЩЕНО:** 🔥🚀💯 — спам
- Хэштеги: обязательные `#софт`, `#украина`
- CTA: ОБЯЗАТЕЛЬНА ссылка на softzor.com.ua
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО:** российское и белорусское ПО
