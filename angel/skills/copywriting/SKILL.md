# ✏️ Copywriting (для SoftZor)

## Принцип 1. Прозрачность > Яркость
Если нужно выбрать — выбирай понятное.

## Принцип 2. Выгоды > Возможности
Возможность: «Автоматизация отчётов». Выгода: «Экономит 4 часа в неделю бухгалтеру».

## Принцип 3. Конкретика > Размытость
- Размыто: «Улучшите рабочий процесс»
- Конкретно: «Сократите еженедельный отчёт с 4 часов до 15 минут»

## Принцип 4. Язык клиента > Язык компании
Используй слова, которыми клиенты описывают свои проблемы (из отзывов, обращений, тикетов).

## Правило одного
Каждый раздел продвигает ОДНО утверждение. Строй логику сверху вниз.

## Правила стиля

1. Простое > Сложное — «Используй» вместо «утилизируй», «помогай» вместо «облегчай»
2. Конкретика > Размытость — избегай «оптимизируй», «инновационный»
3. Активный залог > Пассивный
4. Уверенность > Оправдания — убери «почти», «очень», «действительно»
5. Покажи > Расскажи — опиши результат вместо прилагательных
6. Честность > Сенсационность — фейковые цифры разрушают доверие

## Проверка качества
- Жаргон непонятен новичку?
- Одно предложение пытается сделать слишком много?
- Есть удивительные знаки? (убери)
- Маркетинговые buzzwords без содержания? (убери)

## Формулы заголовков
- «{Результат} без {Боль}»
- «{Категория} для {Аудитория}»
- «Больше никогда не {Проблема}»
- «{Вопрос главной боли}»

## Запрещённые слова (SoftZor)
инновационный, комплексное решение, уникальный, передовой, единое окно, швейцарский нож, гибкий, лидер рынка

## Структура страницы
| Раздел | Цель |
|--------|------|
| Социальное доказательство | Доверие (логотипы, цифры, отзывы) |
| Проблема/Боль | Покажи понимание |
| Решение/Выгоды | Связь с результатом (3–5 выгод) |
| Как это работает | Убеди в простоте (3–4 шага) |
| Работа с возражениями | FAQ, сравнения, гарантии |
| Финальный CTA | Повтори ценность + призыв к действию |
