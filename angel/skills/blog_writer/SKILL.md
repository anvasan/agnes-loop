# ✍️ Генератор статей блога (SoftZor)

## Когда активировать
- `[контент] Тема` — создать статью на указанную тему
- `[статья] Категория` — написать обзор по категории ПО
- Автопредложение: в категории накопилось 5–6 опубликованных карточек

## Алгоритм работы

### Шаг 1. Проверка готовности категории
```
GET https://softzor.com.ua/wp-json/wp/v2/software?software_category=[id]&lang=ru&status=publish&per_page=100
```
- Менее 3 карточек → предложить создать больше через `software-card`
- 3–4 карточки → можно писать, предупредить «неполный обзор»
- 5+ карточек → идеальное время

### Шаг 2. Исследование темы
- Конкурентные статьи: «ТОП [категория] программ Украина 2025–2026»
- Актуальные тренды в нише
- Ключевые слова для SEO
- Специфика украинского рынка: санкции, локализация, оплата
- Собрать данные о КАЖДОЙ программе на сайте (тарифы, обновления, отзывы)

### Шаг 3. Написание статьи
- **Объём:** 8 000 – 12 000 символов (без пробелов)
- **Язык:** русский

### Шаг 4. Структура статьи (ОБЯЗАТЕЛЬНО)

#### 1. H1 — Заголовок
Формат: `ТОП-N [категория] программ для [целевая аудитория] в Украине [год]`
Пример: «ТОП-7 CRM-систем для малого бизнеса в Украине 2026»

#### 2. Smart Summary (лид)
2–3 предложения, отвечающих на вопрос: «Что я узнаю из этой статьи и зачем мне это?»

#### 3. Почему это важно для Украины
- Санкции на российское ПО, импортозамещение
- Интеграции с Нова Пошта, Monobank, ПриватБанк, ПРРО
- Тренды рынка

#### 4. Критерии отбора
Доступность в Украине, RU/UA интерфейс, оплата из Украины, функциональность, цена/бесплатный тариф

#### 5. Обзор каждой программы
H3 для каждой программы:
```
### [Название] — [характеристика 3-5 слов]

**Страна:** ...
**Цена:** ...
**Сайт:** ...

[2-3 абзаца]

✅ Плюсы:
- ...
❌ Минусы:
- ...
```

#### 6. Сравнительная таблица

| Программа | Бесплатный тариф | Мин. цена | RU/UA | Интегр. УА | Оценка |
|-----------|------------------|-----------|-------|------------|--------|

#### 7. Как выбрать — рекомендации
«Если фрилансер — выбирайте X...», «Если интернет-магазин — подойдёт Y...»

#### 8. FAQ
3–5 вопросов в формате В: / О:

#### 9. Заключение + CTA
Призыв прочитать подробные обзоры на softzor.com.ua

### Шаг 5. SEO-оптимизация (Rank Math meta)
| Параметр | Требование |
|----------|------------|
| rank_math_title | ≤ 55 символов, содержит ключевое слово |
| rank_math_focus_keyword | Основное ключевое слово |
| rank_math_description | ≤ 160 символов |
| Slug | Латиница, содержит ключевое слово |

### Шаг 6. Публикация черновика через WP REST API
```
POST https://softzor.com.ua/wp-json/wp/v2/posts
{
  "title": "...",
  "status": "draft",
  "content": "<h1>...</h1>",
  "meta": {
    "rank_math_title": "...",
    "rank_math_focus_keyword": "...",
    "rank_math_description": "..."
  }
}
```
**НИКОГДА не publish!** Только draft.

### Шаг 7. Пост-публикационные действия
- Предложить пост для Telegram/FB (`social-poster`)
- Сохранить в журнал (`memory_sync`)

## Правила контента

### Тон и стиль
- Дружелюбный эксперт. Как будто опытный коллега советует.
- НЕ: сухой учебник, рекламный буклет, переводная статья
- Максимум 3 предложения в абзаце

### Запрещённые слова
| ❌ Запрещено | ✅ Замена |
|-------------|----------|
| инновационный | современный, новый, актуальный |
| комплексное решение | многофункциональный инструмент |
| уникальный | отличается от конкурентов тем, что... |
| революционный | значительно улучшенный |
| лидер рынка | популярный среди пользователей |

### Факты и достоверность
- Каждое утверждение = факт. Не писать «лучшая CRM» без обоснования.
- ALL программы из категории ДОЛЖНЫ быть упомянуты.
- Выделять программы с реферальной программой.
- Внутренние ссылки на другие статьи и карточки.
