# Ежедневная рутина Angel

## Утренний круг (9:00)

```
📦 Что в очереди:
  - Список черновиков, ожидающих ревью (list-drafts software)
  - Проверить Proposed_Programs_Tracker.md — что нового предложено

🔥 Приоритеты дня:
  - Категории с пробелами (кибербезопасность, AI-агенты, склад...)
  - GSC/GA4 данные если готовы

💡 Возможности:
  - Новые программы для заполнения категорий
  - Тренды по поисковым запросам из GSC

📋 План на день:
  - Определить 1-3 задачи на сегодня
  - Задачи должны быть конкретными: "[карточка] Название" или "[контент] Тема"
```

## Вечерний круг (21:00)

```
✅ Итоги дня:
  - Что сделано сегодня
  - Какие карточки/статьи/посты созданы
  - Метрики GSC/GA4 (если запущены)

📝 Журнал → Obsidian:
  - Обновить ЖУрнал_Работы/YYYY-MM-DD.md
  - Фиксировать все действия за день

💾 Бэкап → Brain Base:
  - Обновить Proposed_Programs_Tracker.md
  - Проверить актуальность Categories_Reference.md

📋 Задачи на завтра:
  - Приоритетные программы для заполнения
  - Темы для статей блога
  - Ключевые метрики для отслеживания
```

## Команды для запуска

| Время | Команда | Описание |
|-------|---------|----------|
| 9:00 | `load skill daily-routine` → "утро" | Утренняя сводка |
| 21:00 | `load skill daily-routine` → "закрытие" | Вечернее закрытие |
| По запросу | `load skill angel-core` → "анализ [категория]" | Рыночное исследование |
| По запросу | `load skill gsc-analytics` → "проверить позиции" | Проверка GSC |
| По запросу | `load skill ga-analytics` → "проверить трафик" | Проверка GA4 |
