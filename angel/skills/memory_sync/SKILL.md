# 🧠 Синхронизация памяти (Memory Sync)

## Триггеры
- Автоматически при создании карточки, статьи, решения
- `[сохранить]` — принудительное сохранение
- `[синхронизация]` — полная синхронизация
- Вечернее закрытие

## Расположение данных

### Obsidian (Google Drive)
| Путь | Назначение |
|------|------------|
| `G:\Мой диск\Obsidian_Brain\Журнал_Работы\YYYY-MM-DD.md` | Ежедневный журнал |
| `G:\Мой диск\Obsidian_Brain\Мои_Скиллы_и_Промпты\Lyra_Commands.md` | Справочник команд |

### Brain Base (Google Drive)
| Путь | Назначение |
|------|------------|
| `...Brain_Base44\01_Context_Master.md` | Контекст проекта, метрики |
| `...Brain_Base44\04_Decisions_Log.md` | Лог решений |
| `...Brain_Base44\Proposed_Programs_Tracker.md` | Трекер программ |

## Операции

### 1. При значимом действии (авто)
- Создана карточка → обновить трекер
- Создана статья → записать в Decisions Log
- Gap-analysis → обнови трекер + Decisions Log

### 2. Запись в лог решений
```markdown
### [YYYY-MM-DD HH:MM] — [Краткое описание]

**Контекст:** ...
**Решение:** ...
**Обоснование:** ...
**Альтернативы:** ...
**Результат:** ...
```

### 3. Вечернее закрытие — Журнал дня
- Создавать файл `Журнал_Работы/YYYY-MM-DD.md`
- **НИКОГДА не перезаписывать существующие журналы!**
- Если существует — дополнить или создать `YYYY-MM-DD_v2.md`

Формат журнала:
```markdown
# 📅 YYYY-MM-DD — Журнал работы

## ✅ Сделано
- [тип] Описание → [ссылка]

## 📝 В процессе
- Задача — текущий статус

## 📋 На завтра
1. Задача с приоритетом
2. Задача с приоритетом

## 💡 Заметки
- Идеи, наблюдения

## 📊 Метрики дня
| Показатель | Значение |
```

### 4. При загрузке контекста (утро / начало сессии)
Читать в порядке:
1. Context Master → метрики
2. Decisions Log → последние 10–15 решений
3. Proposed Programs Tracker → что можно создавать
4. Последний журнал → «На завтра» = сегодняшние задачи

## Правила
1. **НИКОГДА не перезаписывать журналы**
2. ВСЕГДА обновлять поле «Обновлено»
3. Сохранять точность метрик
4. Логировать ВСЕ решения
